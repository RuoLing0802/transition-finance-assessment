`08_国内外知识源抓取与核验台账.xlsx`中的“来源台账”不是命题方官方配套数据，也不是命题方提供的正式知识库。

## 三、本轮必须遵守的统一来源规则

### 1. 外部内容必须提供链接

所有政策、标准、规范、国际框架、论文、行业资料、因子或基准记录，必须在其所在工作表中直接提供可点击的来源链接，不得只在另一张总表中留链接而让使用者自行猜测关联关系。

至少包含以下字段：

| 字段 | 要求 |
|---|---|
| `source_id` | 唯一、稳定，不重复使用旧ID表达新来源 |
| `title` | 来源正式标题 |
| `publisher` | 发布机构、标准发布方或期刊 |
| `document_no_or_standard_no` | 文号、标准号、规范编号或DOI |
| `version` | 版本或发布日期 |
| `effective_date` | 生效日期；未知则标记待核 |
| `official_url` | 官方网页、官方PDF、出版社或DOI链接 |
| `alternate_url` | 可选的备用官方入口，不得用二手转载替代正式来源 |
| `accessed_at` | 最后访问日期 |
| `access_status` | 可访问、403、404、需登录、仅摘要、全文待取得等 |
| `content_completeness` | 全文、部分正文、仅元数据、仅摘要、尚未取得 |
| `verification_status` | 已核验、部分核验、待定位、待全文、不得入库等 |
| `manual_completion_required` | 是/否 |
| `manual_completion_note` | 人工需要补什么、从哪里补、补到哪个字段 |

同一来源被09、10、11、12、13或14号表引用时，该行至少同时保留`source_id`与`official_url`；也可以增加明确的外键并通过公式/静态值带出链接，但交付文件在脱离其他工作簿后仍应让人工看出来源和补录入口。

### 2. 无法取得完整内容时如何处理

如果官方页面存在但全文无法自动抓取，或者遇到403、登录、验证码、付费墙、扫描PDF、附件丢失等情况：

- 不得绕过访问控制；
- 不得根据搜索摘要虚构正文、条款、公式或页码；
- 保留官方入口或DOI；
- 将`content_completeness`标为实际状态；
- 将`manual_completion_required`标为“是”；
- 在`manual_completion_note`中写清人工应下载的文件、需补的章节/页码/表号/全文字段；
- 未取得正文和精确定位的记录不得标记为“条款摘录已核验”或“可正式入库”。

命题方配套Excel、团队内部治理记录等没有外部URL的内容，不得虚构网页链接。应使用仓库相对路径、文件SHA-256、工作表、行号或稳定记录ID进行本地来源追踪，并把`source_type`标记为`competition_dataset`或`governance_record`。

### 3. 来源分级

统一使用以下角色，不得混写：

- `official_policy`
- `official_standard`
- `official_guideline`
- `international_framework`
- `academic_evidence`
- `catalog_candidate`
- `candidate_rule`
- `factor_candidate`
- `benchmark_candidate`
- `governance_record`

候选规则、候选因子、候选基准和研究文献都不得自动执行、计算评分或生成授信结论。
