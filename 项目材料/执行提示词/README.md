# 执行提示词目录

本目录保存当前有效、可直接复制给固定Codex对话或团队成员执行的长提示词。

## 使用规则

- 按负责对话或成果类型建立子目录，例如`03_数据政策评分/`。
- 文件使用Markdown保存，文件名表达阶段、任务和用途。
- 提示词开头记录版本、日期、负责人、执行者和状态。
- 当前有效提示词保存在本目录；已经完成、被替代或失效后移入`项目材料/历史规划/`并标明替代关系。
- 提示词属于执行依据，不替代`docs/PROJECT_PLAN.md`、`docs/PROJECT_STATUS.md`和`docs/DECISIONS.md`中的正式决策。
- 长提示词优先以文件链接交付，避免在对话中重复粘贴全文。
