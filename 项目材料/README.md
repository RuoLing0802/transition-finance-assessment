# 项目材料目录

本目录保存赛题与赛事原文、往届经验参考、当前执行提示词和历史规划输入。

- `赛题与赛事/全部赛题/`：本届全部揭榜赛题，用于横向比较。
- `赛题与赛事/重点赛题/`：本项目第27题的重点入口。该文件与“全部赛题”中的第27题文件内容相同，本轮为便于查找而保留两个入口，未删除原件。
- `赛题与赛事/赛事附件/`：参赛指南和精益画布模板。
- `往届经验参考/`：往届经验图片，仅参考表达和评审偏好，不照搬成果或指标。
- `执行提示词/`：当前有效、可复用的长任务提示词；优先通过文件链接交付，失效后移入`历史规划/`。
- `历史规划/`：已经失效或完成的一次性规划输入，只作追溯，不重新执行。

正式项目状态和决策以根目录`AGENTS.md`及`docs/`中的最新文件为准。
