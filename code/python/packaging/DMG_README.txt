企业转型金融评估
================

这是比赛开发测试版本，使用命题方脱敏模拟数据，不代表真实企业业务数据。
系统不会输出未经验证的正式评分、正式碳排放量或授信通过/拒绝结论。

安装：将“TransitionFinanceAssessment.app”拖入“Applications”文件夹。
运行：双击应用，首次启动可能需要在系统安全设置中允许打开。
数据：运行数据保存在用户应用数据目录，不写入应用安装目录。
macOS：~/Library/Application Support/TransitionFinanceAssessment/

当前版本未完成Apple签名和公证，分发前需由项目负责人补充证书和安装验证。
