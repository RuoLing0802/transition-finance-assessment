# 团队成员成果目录

本目录保存成员直接交付的原始成果，按成员和最接近的十个产品模块归类。成员交付只有经过`01_项目总控与决策`审查并写入`docs/`后，才成为正式项目结论。

- `吴同学/历史分工/`：保存早期团队分工。其固定岗位、开发未启动和AI标签等表述已有部分过时，不更新正式计划或项目记忆。
- `钟同学/05_行业规则与行业对标/`：保存政策、标准、条款、因子和行业覆盖阶段成果。正式采纳范围、冲突和M5边界见[`docs/POLICY_RULES_REVIEW.md`](../docs/POLICY_RULES_REVIEW.md)。

后续新增成果优先沿用“成员/模块或主题”两层结构；不要求任务编号、固定交接包或ZIP格式。
