## 数据使用边界

- `基本信息`、`能耗信息`、`补充信息`是程序输入层。
- `转型目录`是规则与知识来源，当前只有临时行级标识和候选匹配，正式来源、版本、生效期和稳定`rule_id`待确认。
- `转型规划结论`只作参考答案、验证对照或测试基准；不得进入同一模型的训练特征、推理特征、提示上下文或标签生成链路。
- 当前仍缺少独立数据字典、训练/测试划分、正式评分标签、组织/核算边界、Scope口径、排放因子和折标系数。
