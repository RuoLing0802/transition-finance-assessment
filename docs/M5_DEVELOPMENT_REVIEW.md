**结论**：建议采纳并纳入正式工程基线

## 1. 终审结论

M5已经达到当前阶段的正式集成条件。系统新增了本地、可追溯、受记录级准入约束的知识检索层，并保持企业事实、规则、排放因子、评分与证据准入由独立确定性模块管理。M5不是RAG效果验收、规则库完成证明或正式碳核算成果。

本次正式采纳的边界是：

- SQLite保存知识来源、文档、切片、准入决策、治理记录、运行级冻结上下文和检索日志；
- FTS5承担本地确定性检索，FTS5不可用时降级为本地关键词检索；
- 四级可见性为`searchable_candidate`、`metadata_only`、`diagnostic_only`和`blocked`；
- 普通检索只能读取已经由管理员受控构建的索引，不能隐式建库；
- 检索和切片读取绑定`workspace_id`、`assessment_run_id`、`enterprise_id`、派生`thread_id`、企业行业、`knowledge_as_of`和冻结`index_version_id`；
- Agent只增加只读`search_knowledge`工具，外部模型只能解释当前运行实际返回的受控来源摘要；
- `转型规划结论`及其派生内容不进入来源、文档、切片、索引、查询扩展、检索日志正文、模型输入、特征或标签。

## 2. 已通过项

### 2.1 准入与治理

- 以稳定`source_record_id`处理12号731条候选记录，没有重复制造第二组治理对象；
- 当前治理统计为731条，其中`diagnostic_only` 710条、排放因子候选阻断21条；
- 12号候选清单不整表进入普通索引；目录、治理缺口和因子候选继续按记录级边界隔离；
- `metadata_only`只允许来源ID、标准号/文号或规范化完整标题匹配，不参加普通正文相关性召回；
- 准入状态变化形成新的决策记录并通过`supersedes`保留历史链；
- 受控原件使用实际SHA-256，不以文件名替代哈希，不生成虚构文献哈希；
- URL只接受HTTP/HTTPS。

### 2.2 检索、版本与隔离

- FTS5八列权重映射已经修复：三列未索引字段权重为0，标题10、标准号12、章节6、正文1、规范化文本0；
- 索引支持相同版本复用、历史版本保留和当前版本切换；
- 运行首次使用时冻结知识截止日期和索引版本；时间有效性、只有年份的日期不确定状态会进入检索判断和提示；
- `get_chunk`要求切片已由当前运行的检索日志实际返回，并重新校验工作空间、运行、企业、线程、行业和冻结版本；
- Gold隔离探针不再依赖“任意前两个运行”，只选择非`global`且行业明确匹配的源切片，并分别生成源、目标检索日志；
- N-S2-05与N-S2-06分别执行跨企业、跨运行探针；没有合格受控环境时返回`env_blocked`，不误报通过或失败；
- 11行业按正序和逆序创建运行时，Gold分布均稳定为`33 passed / 11 correct_degrade / 0 failed`。

### 2.3 Agent与前端

- 离线流程使用用户真实问题调用检索，并如实展示失败或知识不足；
- 外部模型知识说明使用系统控制摘要，只引用当前运行实际返回的来源ID，不展示私有思维链；
- 右侧“知识依据”面板展示来源角色、冻结版本、截止日期、页码/章节定位、警告、使用边界和官方链接；
- 前端对慢请求和运行切换设置防竞态保护，旧运行的返回结果不能覆盖当前运行面板。

## 4. Gold结果的准确表述

13号44条测试的正式表述是：

```text
33 passed
11 correct_degrade
0 failed
```

`correct_degrade`不是“检索命中”或“检索准确”。它表示期望来源尚未进入当前可用治理资产时，系统没有用其他材料冒充目标，且按测试设计进入证据不足、补问或人工复核边界。不得把本结果改写成`44/44检索准确`、模型效果或真实业务效果。

## 5. 可接受风险与后续事项

- 当前为FTS5/关键词确定性检索，没有Embedding、Reranker、向量数据库、RAGFlow、Qdrant或LlamaIndex；这不阻断当前轻量本地MVP。
- 普通知识检索不自动构建索引。首次使用前需要管理员执行dry-run和受控rebuild；后续可增加独立启动期预构建，但不得由普通查询隐式触发。
- 公开仓库不包含受控PDF原件。干净环境缺失原件时，相关来源必须降级为元数据或阻断，不能伪造正文切片。
- 已增加干净clone回归：没有受控PDF时，19条研究来源全部阻断、研究正文切片为0；当前本机受控环境仍按12篇中文全文生成16个研究片段，7篇英文缺全文继续阻断。
- 11条Gold正确降级反映治理资产缺口，后续由03补齐来源后应重新运行并比较结果，不得修改Gold来迎合当前索引。
- 尚未进行高并发检索性能测试、真实外部模型完整联调或Windows环境验收。
- Vite构建的大体积分包警告和PyMuPDF/SWIG弃用警告登记为非阻断技术债。

## 6. 范围核验

M5没有越界实现：

- 正式碳排放核算、排放因子自动调用；
- 行业基准、转型行为、正式评分或信贷支持建议；
- OCR扩展、RAGFlow或向量数据库；
- Windows EXE/MSI；
- 竞赛报告扩展。

当前新增因子允许自动调用仍为0条。国家温室气体排放因子库在M5中只承担来源索引和适用性元数据角色；具体因子值必须在M6通过版本冻结、条目级准入和适用性审查后才能参与计算。
