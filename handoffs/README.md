# 团队成员成果可选存档目录

`handoffs/`保留用于需要长期留档、材料较多或便于打包的成员成果，但不是成员开始或完成任务的必要路径。成员可以把建议、反馈、文档、代码片段、数据结果或ZIP直接发送给若翎。

如选择使用本目录，可按成员、主题或日期自行建立清楚的子目录。任务编号、固定目录层级、`HANDOFF.md`、`SYNC_PROMPT.md`、固定ZIP结构和“我要同步”口令均不作强制要求。详细流程见 [`docs/SYNC_WORKFLOW.md`](../docs/SYNC_WORKFLOW.md)。

成员不向正式GitHub仓库提交、推送、创建分支或Pull Request。若翎在 `01_项目总控与决策` 中审查材料并确认采纳后，才由若翎或明确授权的Codex更新正式项目。

本目录中的交付内容只有经过若翎审查、确认和集成后，才视为正式项目成果。
