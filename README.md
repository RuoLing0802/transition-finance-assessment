# 第五届中国研究生金融科技创新大赛：转型金融评估

## 项目定位

围绕“碳迹可循，绿贷智评：基于多维度数据与行业标准的企业转型金融评估系统”开展研究、数据分析、评估模型和系统展示。

## 当前状态

- 阶段：项目初始化，待补充正式揭榜任务书、数据要求、评价指标和时间节点
- 赛题方向：企业转型金融评估
- 题目来源：江西普惠征信
- 最终交付物：待根据正式赛题文件确认

## 目录说明

- `docs/`：赛题文件、研究设计、指标口径、系统方案和会议纪要
- `data/raw/`：原始数据，只读，不直接覆盖
- `data/interim/`：清洗、匹配和特征工程过程数据
- `data/processed/`：建模和展示用最终数据
- `code/python/`：数据处理、建模和系统原型代码
- `code/stata/`：需要时使用的计量分析脚本
- `output/`：评估结果、图表、报告、答辩材料和演示资源
- `references/`：政策、标准、文献和行业资料
- `logs/`：运行日志和版本记录
